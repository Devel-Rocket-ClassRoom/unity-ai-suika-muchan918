# 수박 게임 (Suika Game) 핵심 메카닉

## 1. 게임 개요

- **장르**: 물리 기반 낙하 + 합치기(Merge) 퍼즐
- **목표**: 컨테이너(상자)에서 과일이 넘치기 전까지 같은 과일을 합쳐 더 큰 과일을 만들고 점수 획득
- **제한 시간**: 없음 (전략적 플레이 가능)

---

## 2. 핵심 메카닉

### 2-1. 드롭 & 머지 (Drop & Merge)
- 플레이어는 상자 **위쪽에서 과일을 떨어뜨림** (좌우 위치 조절 가능)
- **같은 종류의 과일 2개가 닿으면** 한 단계 더 큰 과일로 합쳐짐
- 합쳐질 때마다 점수 획득

### 2-2. 물리 시뮬레이션
- 과일들은 **중력의 영향**을 받아 떨어지고 굴러다님
- 다른 과일에 부딪히면 **튕기고 굴러서** 예측 불가능한 위치에 안착
- Unity의 `Rigidbody2D` + `CircleCollider2D`로 구현

### 2-3. 게임 오버 조건
- 과일이 상자 **상단의 "라인"을 넘어가면** 게임 종료
- 즉시 종료가 아닌 grace period 존재 (일정 시간 이상 라인 위에 머무르면 종료)

### 2-4. 다음 과일 미리보기
- 플레이어가 떨어뜨릴 과일은 **랜덤하게 결정**됨
- **다음 1개의 과일은 미리 표시**되어 전략적 배치 가능

### 2-5. 드롭 가능한 과일 제한
- 11종 과일 중 **가장 작은 5종만** 직접 드롭 가능
  - 체리, 딸기, 포도, 데코폰, 감
- 나머지 6종은 **합치기로만** 생성 가능

---

## 3. 과일 진화 사이클 (11종)

| 순서 | 과일 | 합치는 점수 | 드롭 가능 |
|---|---|---|---|
| 1 | 체리 (Cherry) | +2 | O |
| 2 | 딸기 (Strawberry) | +3 | O |
| 3 | 포도 (Grape) | +4 | O |
| 4 | 데코폰 (Dekopon) | +5 | O |
| 5 | 감 (Persimmon) | +6 | O |
| 6 | 사과 (Apple) | +7 | X |
| 7 | 배 (Pear) | +8 | X |
| 8 | 복숭아 (Peach) | +9 | X |
| 9 | 파인애플 (Pineapple) | +10 | X |
| 10 | 멜론 (Melon) | +11 | X |
| 11 | 수박 (Watermelon) | 최종 | X |

> **점수 규칙**: n번째 단계 합치기 = `+(n+1)` 점 (예: 체리+체리=딸기 → +2점)

### 특별 규칙
- **수박 + 수박** → 더 큰 과일로 진화하지 않고 **둘 다 그대로 소멸**
  - 큰 보너스 점수 획득
  - 보드 공간이 크게 비워져 게임을 이어가기 유리해짐
  - 게임 내 사실상 최고 난도 목표 (엔딩에 가까움)
- **3,000점 이상**이 비공식 도전 목표

## 4. Unity 구현 시스템 설계

### 필요한 모듈

1. **과일 데이터 (ScriptableObject)**
   - 레벨(0~10), 스프라이트, 반지름, 점수, 색상

2. **드롭 컨트롤러**
   - 마우스/터치로 X좌표 이동
   - 다음 과일 미리보기 UI
   - 드롭 쿨다운 (연속 드롭 방지)

3. **과일 프리팹**
   - `Rigidbody2D` (중력, 마찰)
   - `CircleCollider2D` (충돌)
   - 충돌 시 머지 판정 스크립트

4. **머지 로직**
   - `OnCollisionEnter2D`에서 같은 레벨 감지
   - 두 과일 위치의 중간점에서 다음 레벨 과일 생성
   - 중복 머지 방지 (동시 충돌 처리)

5. **게임 오버 감지**
   - 상단에 트리거 라인 (`BoxCollider2D` isTrigger)
   - 일정 시간 이상 라인 위에 과일이 머무르면 종료

6. **점수 / UI**
   - 현재 점수, 다음 과일 미리보기, 게임 오버 화면

### 핵심 도전 과제
- **동시 충돌 처리**: A-B, B-C가 같은 프레임에 머지될 때 B가 두 번 사라지는 버그 방지 (플래그 또는 큐 사용)
- **물리 안정성**: 과일이 끼이거나 튀어오르지 않도록 마찰/탄성 조정
- **머지 시점의 시각·사운드 피드백**
